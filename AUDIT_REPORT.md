# Аудит стратегии: Island Model of Random Trees для MOEX

## 1. Описание стратегии

### Архитектура
**Island Forest** — ансамбль из 6 независимых "островов" (подпопуляций деревьев решений),
объединённых кольцевой миграцией лучших деревьев.

- **Острова**: 4× RandomForest + 2× ExtraTrees с различными гиперпараметрами
  (max_depth, max_features, min_samples_leaf)
- **Миграция**: каждые 3 раунда лучшие деревья с острова `i` перемещаются
  на остров `(i+1) % 6`, заменяя случайные деревья (не худшие — для разнообразия)
- **Агрегация**: взвешенное голосование, веса ∝ точности на хронологической валидации
- **Всего деревьев**: 6 × 50 = 300

### Признаки (46 штук)
| Категория | Признаки |
|-----------|----------|
| Доходности | ret_5, ret_10, ret_20, ret_60 |
| Волатильность | vol_5, vol_10, vol_20, vol_60 |
| Объёмные | volume_ratio_5/10/20/60, OBV z-score, PVT z-score, volume_ma_ratio |
| High-Low range | high_low_range_5/10/20/60 |
| Осцилляторы | RSI(14), Stochastic K/D, Williams %R, CCI(20) |
| Тренд | MACD histogram, ADX(14), Bollinger %B/Width |
| Ichimoku | tenkan/kijun vs close, cloud width |
| Календарные | day_sin/cos, month_sin/cos, month_end |
| Межрыночные | USDRUB ret 5/20/vol, Brent ret 5/20, Brent_RUB ret, oil-rub корреляция |

### Торговая логика
1. Сигнал формируется по данным дня **T-1** (последние известные close/volume)
2. Если `P(рост) > 0.55` → LONG, иначе → CASH (нет шортов)
3. Исполнение по цене **open дня T+1** (задержка 1 день)
4. Равномерная аллокация среди long-сигналов, max 25% на тикер
5. Позиции округляются до лотов MOEX

### Walk-Forward параметры
- Обучение: 252 дня (1 год)
- Embargo: 5 дней (= горизонт таргета)
- Переобучение: каждые 21 день (~месяц)
- Таргет: бинарный, forward return за 5 дней > 0

## 2. Найденные ошибки и проблемы

### КРИТИЧЕСКИЕ

#### 2.1. Данные НЕ реальные
**Severity: CRITICAL**

CSV-данные в `/data/` — это **интерполяция между контрольными точками** с GARCH-шумом,
а не настоящие биржевые данные MOEX. Все внешние источники данных были заблокированы
прокси-сервером (MOEX ISS API, Yahoo Finance, Kaggle, QScalp).

Последствия:
- Микроструктура цен синтетическая
- Внутридневная динамика (open/high/low) сгенерирована, а не наблюдена
- Объёмы сгенерированы по модели, не отражают реальную ликвидность
- **Результаты бэктеста нельзя считать достоверными**

#### 2.2. MOEX была закрыта с 25.02 по 24.03.2022 — в данных есть торговля
**Severity: CRITICAL**

В реальности Московская биржа была полностью закрыта с 25 февраля по 24 марта 2022.
В наших данных присутствуют торговые дни: 2022-02-25, 2022-02-28, 2022-03-01, ... 2022-03-24.

Это значит:
- ~20 торговых дней в данных — **фиктивные**
- Любые сделки модели в этот период невозможны в реальности
- Модель могла "заработать" на постепенном снижении, которое в реальности было гэпом -50%

#### 2.3. Look-ahead bias в position sizing (незначительный)
**Severity: LOW**

В `portfolio_backtester.py:336`:
```python
target_value = (cash + self._portfolio_value(positions, ohlcv, current_date, ticker_datasets)) * alloc
```

`_portfolio_value()` использует `close` текущего дня для оценки портфеля,
но сделки исполняются по `open` того же дня. Цена `close` ещё не известна
в момент открытия. Влияет только на **размер** позиции (не на направление).

**Оценка impact**: <0.5% на итоговый P&L — незначительно.

### УМЕРЕННЫЕ

#### 2.4. Sharpe Ratio посчитан с rf=21% для всего периода
**Severity: MODERATE**

Безрисковая ставка 21% (ключевая ставка ЦБ РФ) применена ко всему периоду 2019-2024.
В реальности:
- 2019: 7.75% → 6.25%
- 2020: 6.25% → 4.25%
- 2021: 4.25% → 8.5%
- 2022: 8.5% → 20% → 7.5%
- 2023: 7.5% → 16%
- 2024: 16% → 21%

Средняя ≈ 10%. С rf=10% Sharpe был бы значительно выше (excess return +8.1% vs -2.9%).

#### 2.5. Survivorship bias
**Severity: MODERATE**

Тестируются только 5 крупнейших ликвидных акций, которые "выжили" к 2024 году.
Компании, которые были исключены из индекса или обанкротились, не учтены.

#### 2.6. Кризис февраля 2022 сглажен
**Severity: HIGH**

В реальности СБЕР упал с ~290 руб. до ~100 руб. (гэп -65% при открытии 24 марта).
В наших данных падение плавное: 244 → 124 руб. (постепенно за 2 месяца).

Модель в реальности бы:
- Имела открытые позиции 24.02.2022
- Не могла их закрыть до 24.03.2022
- Понесла бы убыток ~40-60% портфеля за один день переоценки

### НЕЗНАЧИТЕЛЬНЫЕ

#### 2.7. Объёмы в слипедж-модели
Market impact `sqrt(trade_vol / market_vol)` для 100K портфеля практически нулевой.
Это реалистично — маленький портфель не двигает рынок.

#### 2.8. Commission per side vs per round trip
Комиссия 0.04% per side (0.08% round trip) — это реалистичный тариф для Тинькофф/БКС.

## 3. Что посчитано ПРАВИЛЬНО

✅ **Look-ahead bias в сигналах**: сигнал формируется по T-1, исполняется по T+1 open — корректно

✅ **Embargo**: 5 дней embargo ≥ 5 дней target horizon — нет утечки таргета в обучение

✅ **Walk-Forward**: хронологическое разделение train/val/test, без перемешивания

✅ **Комиссии**: 0.04% per side реалистично для российских брокеров

✅ **Лоты MOEX**: SBER=10, GAZP=10, LKOH=1, GMKN=1, ROSN=1 — корректно

✅ **Проскальзывание**: half-spread + market impact — адекватная модель для малых портфелей

✅ **Ограничение позиции**: max 25% на тикер — разумный risk management

✅ **OHLC consistency**: high ≥ max(open, close), low ≤ min(open, close) в данных

✅ **Переобучение**: ежемесячное переобучение реалистично для production

## 4. Оценка для живой торговли

### НЕ РЕКОМЕНДУЕТСЯ для live trading в текущем виде

| Критерий | Оценка | Комментарий |
|----------|--------|-------------|
| Данные | ❌ | Синтетические, не реальные |
| Кризис 2022 | ❌ | Не учтена остановка биржи |
| Sharpe (rf=21%) | ⚠️ | Отрицательный (-0.4), не бьёт депозит |
| Sharpe (rf=10%) | ✅ | Положительный, но на синтетике |
| MaxDD | ⚠️ | -13.86% заниженный (реально было бы 40-60%) |
| Торговые издержки | ✅ | Реалистичная модель |
| Архитектура | ✅ | Корректная реализация Island Model |
| Код бэктеста | ✅ | Нет грубых ошибок |

### Что нужно для допуска к live trading:

1. **Реальные данные MOEX** — минимум 5 лет дневных OHLCV с правильными торговыми днями
2. **Правильная обработка закрытия биржи** (25.02-24.03.2022):
   - Позиции замораживаются
   - При открытии — переоценка по gap price
   - Это уничтожит значительную часть прибыли
3. **Динамическая безрисковая ставка** вместо фиксированных 21%
4. **Paper trading** минимум 3-6 месяцев перед реальными деньгами
5. **Stress-тестирование**: Monte Carlo симуляции кризисных сценариев
6. **Out-of-sample валидация** на данных, которые модель не видела при разработке

### Грубая оценка реальной доходности:

С учётом кризиса 2022 (гэп -50% по портфелю при ~100% invested):
- Портфель: 100K → ~50K (март 2022) → восстановление
- Итоговый результат: существенно хуже показанных +124%
- Вероятная итоговая доходность: **+20..+60%** за 5 лет (4-10% годовых)
- Против депозита ЦБ (~10% средних за период): **стратегия может проиграть**

## 5. Резюме

Архитектура Island Forest **реализована корректно**, бэктестер **не содержит грубых ошибок**
в части look-ahead bias и торговой логики. Однако результаты **недостоверны** из-за
синтетических данных и отсутствия реального кризиса февраля 2022.

**Для принятия решения о live trading необходимо:**
1. Прогнать бэктест на реальных данных MOEX (Kaggle / MOEX ISS / Finam export)
2. Убрать торговые дни, когда биржа была закрыта
3. Добавить stress-test с гэпом -50% при открытии 24.03.2022
4. Сравнить с банковским депозитом и индексным фондом (TMOS)

Только после этого можно оценить реальную alpha стратегии.
